# Research Shelf 사용 설명서

옵시디언을 처음 쓰는 사람을 위한 설명입니다. 화면의 버튼 이름은 플러그인에 적힌 그대로입니다.

아래 그림은 예시 화면입니다. 실제 옵시디언 창의 메뉴 위치와 다를 수 있습니다.

## 바로 시작

1. [설치](01-설치.md)하고 커뮤니티 플러그인에서 Research Shelf를 켭니다.
2. 명령 팔레트에서 **자료 검색**을 실행합니다.
3. 고른 자료를 **선택한 n개 저장**으로 노트에 남깁니다.

계정이나 Firebase 없이 여기까지 됩니다.
