# 자주 묻는 질문

## 인증 메일이 안 옵니다

스팸함을 확인합니다. 플러그인의 **인증 메일 다시 보내기**를 누릅니다. **팀에 들어가기** 창에서는 가입이나 로그인을 한 번 한 뒤에 그 버튼이 나타납니다.

메일의 링크를 누르기 전에 팀에 들어가려 하면 **메일을 확인해 주세요. 받은 편지함의 링크를 누른 뒤 다시 로그인해 주세요.**가 나옵니다. 링크를 누른 뒤 **로그인**을 다시 눌러야 합니다. 인증 전에 만든 로그인 상태는 메일 확인이 반영되지 않습니다.

## 팀코드 오류와 메일 인증을 구분합니다

인증이 아직이면 **메일 인증이 필요해요**입니다. 메일을 확인한 사람인데 코드가 틀리면 **팀코드가 맞지 않아요. 관리자에게 새 초대 링크를 받아 주세요.**입니다. 관리자가 코드를 바꾸거나 **멤버 빼기**를 하면 이전 링크는 멈춥니다.

관리자가 메일 인증 전에 서고나 초대 링크를 만들면, 초대 링크를 다시 받으라는 말 대신 메일 인증 안내가 나옵니다.

## 키 오류

KCI, RISS, AI 키가 없거나 틀리면 그 출처나 요약만 실패합니다. 다른 출처 검색과 이미 저장한 노트는 그대로입니다. 화면의 **키 필요**, **기관 키 필요**를 확인합니다. 키는 설정에 다시 넣고, 필요 없으면 **키 지우기**를 누릅니다.

영진위, 콘진원, OpenAlex가 응답하지 않으면 각각 **영진위가 응답하지 않았어요**, **콘진원이 응답하지 않았어요**, **OpenAlex가 응답하지 않았어요**처럼 나옵니다. **다시 검색**으로 한 번 더 시도합니다.

## 네트워크로 무엇이 나가나

검색과 요약을 쓸 때만 나갑니다. PDF를 노트로 바꾸는 일은 이 컴퓨터 안에서 합니다.

- 검색어는 영화진흥위원회, 한국콘텐츠진흥원, OpenAlex로 갑니다. KCI와 RISS는 키를 넣은 뒤에만 갑니다.
- AI 요약을 켜면 고른 회사(Gemini, OpenAI, Anthropic)로 요약할 글이 갑니다.
- 내 클라우드나 팀 서고에 올리면 그 Firebase로 노트 내용이 갑니다.
- 브리핑 사이트는 브라우저에서 Firestore를 읽습니다.

## 개인정보

- 혼자 쓰기: 이 보관함을 연 사람만 봅니다.
- 내 클라우드: 올린 사람만 읽고 씁니다. **브리핑에 공개**를 켠 글만 웹에 나옵니다.
- 팀: 팀코드를 맞추고 인증한 뒤 가입한 사람만 씁니다. 공개로 둔 글은 로그인 없이 브리핑에서 볼 수 있습니다.
- 브리핑에는 메일 주소가 아니라 **표시 이름**이 나옵니다.
- 비밀번호와 API 키는 노트와 깃허브에 저장하지 않습니다.

## 규칙이 잠김

`__LABSIDIAN_ADMIN_UID__`가 그대로인 규칙을 게시하면 서고를 만들 수 없습니다. 로그인한 뒤 **규칙 복사**로 받은 글을 다시 게시합니다.
