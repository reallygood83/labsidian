# Vercel 브리핑

브리핑은 최근 7일 동안 공개한 글을 보여주는 웹 페이지입니다. 로그인하지 않아도 볼 수 있습니다. 서비스 계정 키는 쓰지 않습니다.

## 배포

1. 플러그인 **팀 서고** 탭에서 **브리핑 배포용 값 복사**를 누릅니다. 안내가 **배포용 값을 복사했어요. Vercel의 NEXT_PUBLIC_LABSIDIAN_CONFIG에 붙여 넣어요.**입니다.
2. 그 값은 웹 앱 설정과 팀 번호가 들어 있는 공개용 문자열입니다. 비밀번호나 서비스 계정 키는 들어 있지 않습니다. 그래도 채팅방에 올리지 않는 편이 안전합니다.
3. [Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Freallygood83%2Flabsidian&project-name=labsidian-briefing&root-directory=briefing&env=NEXT_PUBLIC_LABSIDIAN_CONFIG)에서 이 저장소를 가져옵니다. 루트 디렉터리는 `briefing`입니다.
4. 환경 변수 `NEXT_PUBLIC_LABSIDIAN_CONFIG`에 복사한 값을 넣습니다.
5. 배포가 끝나면 그 주소를 플러그인의 **브리핑 주소**에 넣습니다. 올리기가 끝나면 **브리핑 보기** 버튼이 그 주소를 엽니다.

값이 없으면 페이지는 **주간 브리핑**과 함께, 환경 변수에 배포용 값을 넣으면 최근 7일을 보여 준다고 안내합니다.

값이 있으면 제목이 **주간 브리핑**이고, **로그인 없이 볼 수 있어요.**가 나옵니다. 최근 7일에 글이 없으면 **최근 7일에 올라온 자료가 없어요.**입니다.

## Obsidian에서 열기

컴퓨터 브라우저의 카드에 **Obsidian에서 열기**가 있습니다. 휴대폰에서는 이 링크를 숨깁니다. 링크는 `obsidian://labsidian?id=문서번호` 형식이고, 문서 번호로 보관함의 노트를 찾습니다. 없으면 서고에서 받아 노트를 만듭니다. 이미 같은 문서 번호가 있으면 새 노트를 만들지 않습니다.

잠긴 글은 비밀번호를 물어봅니다. [문서 잠금](05-문서-잠금.md)을 참고합니다.
