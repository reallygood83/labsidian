# 설치

옵시디언 1.11.4 이상, 컴퓨터용 앱에서만 됩니다. 휴대폰 앱은 지원하지 않습니다.

설정에서 제한 모드가 켜져 있으면 어떤 방법으로 넣어도 플러그인이 켜지지 않습니다. 먼저 아래를 합니다.

1. 왼쪽 아래 톱니바퀴로 **설정**을 엽니다.
2. **커뮤니티 플러그인**을 엽니다.
3. **제한 모드**를 끕니다.

## BRAT으로 설치

BRAT은 깃허브에 올라온 시험판 플러그인을 받아 주는 도구입니다. 릴리스(배포 묶음)가 있어야 받아 옵니다. 릴리스가 아직 없으면 다음 절의 직접 넣기를 사용합니다.

1. 커뮤니티 플러그인에서 **탐색**을 눌러 BRAT을 설치하고 켭니다.
2. 명령 팔레트(`Ctrl+P` 또는 `Cmd+P`)에서 `BRAT: Add a beta plugin`을 실행합니다.
3. 주소에 `reallygood83/labsidian`를 넣습니다.
4. 다시 커뮤니티 플러그인 목록에서 **Labsidian**을 켭니다.

## 파일을 직접 넣기

릴리스에 있는 파일 세 개만 필요합니다.

- `main.js`
- `manifest.json`
- `styles.css`

1. 옵시디언에서 지금 연 보관함(볼트) 폴더를 찾습니다. 다른 이름으로 바꾸지 않은 폴더는 보통 문서 안에 있습니다.
2. 그 안에 `.obsidian/plugins/labsidian` 폴더를 만듭니다. `.obsidian`은 숨은 폴더일 수 있습니다.
3. 위 세 파일을 그 폴더에 넣습니다. 다른 파일을 더 넣지 않아도 됩니다.
4. 옵시디언을 다시 실행하거나, 커뮤니티 플러그인 목록을 새로고침합니다.
5. **Labsidian** 스위치를 켭니다.

왼쪽 리본(세로 아이콘 줄)에 돋보기가 생기면 설치된 것입니다. 그 아이콘 이름이 **자료 검색**입니다.
